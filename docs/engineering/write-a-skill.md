## What it does

Create a focused reusable workflow with discriminating metadata, progressive disclosure, and checkable completion. Package resources earn their place through a necessary execution boundary.

## When to reach for it

Type this skill or ask to create or improve a reusable skill.

## Prerequisites

The target project and the inputs/authority required by the owning task. Preserve its existing setup and documentation.

## Common questions

**Should every workflow gain a helper script?**

No. Scripts belong only where they own necessary deterministic, repeated, failure-sensitive work.

## It's working if

- The skill triggers for its intended task and avoids the neighboring non-trigger.
- Referenced files, metadata, and representative scenarios are checked.
