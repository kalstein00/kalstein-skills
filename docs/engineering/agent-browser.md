## What it does

Operate the actual web or Electron target through the project-approved CLI route. Installed version-matched instructions and a named session keep the tool and target explicit.

## When to reach for it

You can type this skill or the agent can select it for navigation, forms, screenshots, or live UI acceptance.

## Prerequisites

The target project's runnable app, data, approved Agent Browser route, and applicable test/session instructions. Required live capability must be available before production UI edits.

## Common questions

**Does installing the plugin also install Agent Browser?**

No. The target project owns its wrapper, pinned CLI, app launch, data, and attachment discovery. Missing required live capability is reported precisely.

## It's working if

- The recorded session is attached to the intended non-blank app.
- The report describes actual UI actions and selected screenshots have been opened for inspection.
