# Zoom Out

Perform read-only orientation unless implementation is explicitly requested.

Map the entrypoints, owning Modules, upstream callers, downstream dependencies/state, authoritative Interfaces, domain terms, and change/testing seams one abstraction layer above the current file. Distinguish verified code evidence from inference and name material unknowns.

Do not merely summarize the current file or begin refactoring. Use project glossary vocabulary and end with the smallest useful navigation or investigation next step.
